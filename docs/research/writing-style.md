# 台灣新聞寫作風格研究：中央社（CNA）與《報導者》（The Reporter）分析

本研究旨在建立《經濟學人》（The Economist）中文導讀專案的繁體中文（台灣習慣用語）新聞編輯準則，以消除語意僵硬的英文翻譯腔（Translationese），使標題與內文摘要符合台灣主流嚴肅新聞媒體之專業水準。

---

## 一、研究樣本與方法

本研究分析於 2026 年 10 月初採集的兩份代表性台灣媒體語料：
1. **中央通訊社（CNA）國際新聞**：共取樣 45 則即時與專題國際新聞（含標題、導言與內文句構）。
2. **《報導者》（The Reporter）國際與解釋性報導**：共取樣 12 則國際專題、深度調查與解釋性報導（含標題結構、前言引導與結構性框架）。

---

## 二、中央社（CNA）風格分析（News Wire House Style）

中央社為台灣國家通訊社，其國際新聞編譯風格代表台灣主流客觀新聞寫作標準，具備高度凝練、事實精確與節奏俐落等特質。

### 1. 標題語法規範
- **字數長度**：主要介於 14–26 字之間，極少超過 28 字。
- **全形空格「　」斷句**：
  標題若包含兩層邏輯（如主從句、因果、主體＋行動、背景＋核心衝突），一律以**全形空格「　」**分隔，不使用逗號「，」或斜線「/」。
  - 例：[烏克蘭空襲俄羅斯煉油廠　宣稱癱瘓51%產能](https://www.cna.com.tw/news/aopl/202610050312.aspx)
  - 例：[歐洲國防基金計畫收件量創新高　烏克蘭首度參與](https://www.cna.com.tw/news/aopl/202610050289.aspx)
  - 例：[菲中緊張升溫　孔子學院志願教師也陸續撤離](https://www.cna.com.tw/news/aopl/202610050273.aspx)
  - 例：[丹麥政府人口登記系統遭駭　880萬人個資外洩](https://www.cna.com.tw/news/aopl/202610050278.aspx)
- **冒號「：」嚴格限於發言主體與引述**：
  中央社標題絕不將冒號當作破折號或同位語使用，僅用於引出特定發言者、機構或來源的立場：
  - 例：[為保自主與美貿易談判陷僵局　印度財長：很難再讓步](https://www.cna.com.tw/news/aopl/202610050258.aspx)
  - 例：[CNBC：美財政末日未到　公債殖利率飆升恐釀債務螺旋](https://www.cna.com.tw/news/aopl/202610050206.aspx)
  - 例：[日銀：AI熱潮帶動需求　金融環境轉寬鬆但有回檔風險](https://www.cna.com.tw/news/aopl/202610050105.aspx)
  - 例：[民主礁再爆空中對抗　菲律賓：巡邏機遭中國殲16逼近](https://www.cna.com.tw/news/aopl/202610050084.aspx)
- **禁用問號「？」**：
  即時新聞標題採陳述句，交代最新事實或爭端焦點，絕不採用「…嗎？」等修辭性問句。即使涉及未知情勢，亦改採主動或評估動詞（如「恐難成局」、「成敗受矚」）。
- **強力單音節與雙音節主動動詞**：
  標題偏好強動詞以維持緊湊張力：
  - 控、批、擬、恐、創、遭、獲、拚、揭、陷、飆、釀、襲、示警、重挫、加碼。
  - 例：[美學者獲諾貝爾醫學獎　自稱「夜貓子」獲獎後沒睡飽](https://www.cna.com.tw/news/aopl/202610050300.aspx)
  - 例：[德法認歐盟反經濟脅迫工具太慢　推新機制強化嚇阻中國](https://www.cna.com.tw/news/aopl/202610050250.aspx)
  - 例：[梅爾茨訪基輔宣布加碼軍援 稱德不因威脅而退縮](https://www.cna.com.tw/news/aopl/202610050059.aspx)
- **阿拉伯數字與專有名詞縮寫**：
  - 數量、百分比、日期、金額全面採用阿拉伯數字：`51%`、`880萬人`、`50%`、`3.2億美元`、`11/29`。
  - 標題一律簡化專有名詞以節約字數：寫「AI」而不寫「人工智慧」（如：[挪威擬特定場所禁AI眼鏡　防民眾遭偷拍、錄影和錄音](https://www.cna.com.tw/news/aopl/202610050244.aspx)）。
- **標準台灣譯名規範**：
  - 人名：川普、普丁、澤倫斯基、盧比歐、高市早苗、梅爾茨、希塔拉曼、桑傑士、卡尼、施凱爾、納坦雅胡、莫迪、金正恩。
  - 企業與技術：輝達（Nvidia）、台積電（TSMC）、開放權重模型（Open-weight model）。

### 2. 導言（Lead Paragraph）結構
- **倒金字塔格式**：第一句明確回答人、事、時、地、核心行動（5W1H），背景補充置於第二句或後續段落。
- **電頭規範**：`（中央社地名X日綜合外電報導）` 或 `（中央社記者XXX地名X日專電）`。
- **客觀引述動詞**：以「表示」、「指出」、「宣布」、「透露」、「警告」客觀陳述，避免「大秀」、「力抗」等帶有主觀情緒色彩的宣傳用語。

## 三、《報導者》（The Reporter）風格分析（Explanatory Journalism House Style）

《報導者》為台灣非營利深度調查與解釋性報導媒體，其報導形式適合導讀《經濟學人》的深度分析與專案企劃。

### 1. 議題框架（Framing）特點
- **結構性提問與矛盾張力**：
  《報導者》常用對比與結構性問題作為副標或導讀核心，點出體制矛盾：
  - 例：[中國孔子學院退場，台灣華語教學進場？繁體中文、台灣特色進入澳洲市場的機會與門檻](https://www.twreporter.org/a/taiwan-center-for-mandarin-learning-in-australia)
  - 例：[電網端儲能供過於求，建置中大型案場何去何從？台中豐原案爭議揭政策難題](https://www.twreporter.org/a/billion-sun-siting-controversy-and-grid-energy-storage-policy)
  - 例：[從天而降的「高山海嘯」：冰河退縮、救災矛盾和沉默的跨境預警，如何加劇尼泊爾世紀洪災？](https://www.twreporter.org/a/hello-world-2026-08-31)
- **以個體經驗錨定宏觀政策**：
  在前言常帶入關鍵人物的具體心境或現場引言，將龐大的地緣政治或法律爭議具體化：
  - 例：[當中共把「愛」變成傷人武器：跨國鎮壓對香港社群的心理試煉](https://www.twreporter.org/a/china-transnational-repression-hong-kong-psychological-toll-anna-kwok)
  - 例：[專訪《反對普丁的無名先生》導演：小學老師如何用800天記錄校園裡重製「戰鬥民族」的荒謬真實](https://www.twreporter.org/a/interview-david-borenstei-mr-nobdy-against-putin)
- **政策反思與系統性成因**：
  在內文分析時，跳脫非黑即白的二元對立，探討制度運作的代價與政策兩難（Trade-offs）：
  - 例：[法國《協助死亡法案》，一場自由、平等與博愛纏鬥半世紀的生命論戰](https://www.twreporter.org/a/hello-world-2026-07-23)
  - 例：[台灣資料中心用電壓力大？全球AI熱潮下的區域電網新挑戰](https://www.twreporter.org/a/data-center-electricity-demand)

### 2. 對《經濟學人》導讀的應用啟示
- **標題**：以中央社的緊湊、動詞驅動（Verbs-driven）為主體（12–24 字，雙子句全形空格相連），兼具中央社的清晰與經濟學人的觀點鋒芒。
- **內文摘要與背景解析**：借鑑《報導者》的背景問題意識與政策兩難框架，避免流水帳式翻譯，直接點出文章的核心論點與對台灣或全球秩序的深層衝擊。

## 四、翻譯腔（Translationese）黑名單與自然置換對照表

英文新聞直譯常產生冗言贅字、空洞虛詞及結構倒裝。以下彙整台灣讀者最反感的直譯套路與自然台媒新聞用語置換：

| 類別 | 翻譯腔 / 劣質直譯 | 問題分析 | 自然台灣新聞置換建議 |
| :--- | :--- | :--- | :--- |
| **虛詞動詞化** | 進行訪問、進行會談 | 英文 "conduct a visit / hold talks" 的無效直譯 | 訪問、造訪、出訪；會談、會晤 |
| | 作出決定、作出回應 | 英文 "make a decision / response" | 決定、拍板；回應、答覆 |
| | 對…進行打擊/調查 | 英文 "carry out strikes on / investigate" | 打擊、空襲；調查、立案追查 |
| **空洞連接詞** | 隨著…的到來 / 隨著…發展 | 英文 "With the advent of..."，句構鬆散拖沓 | 因、鑑於；在…之際；值此…關頭 |
| | 基於…的理由 | 英文 "based on..."，公文式贅字 | 因、考量到、著眼於 |
| **公文陳腔** | 該國、該機構、該計畫 | 頻繁使用「該」，行文如起訴書或公文 | 這個國家、此機構、這項計畫、相關組織 |
| | 存隱憂 | 語意模糊陳腐，缺乏具體威脅描述 | 恐難成局、藏變數、現隱患、埋下未爆彈 |
| | 面臨消長 | 空泛抽象，未指出具體態勢 | 態勢逆轉、首度超越、差距拉大、主客易位 |
| **生硬直譯** | 接熱線 | 直譯 "answer the phone/hotline"，不合中文語感 | 通話、接聽危機專線、開啟熱線對話 |
| | 大秀（大秀肌肉） | 俗劣套話，不符嚴肅媒體筆調 | 展現實力、展示軍力、彰顯影響力 |
| | 力抗 | 濫用套語，缺乏戰術細節 | 抵禦、抗衡、防堵、正面交鋒 |
| | 開創新局 | 泛濫的套話 | 開啟新頁、迎來轉機、注入新動能、拓展新路徑 |
| **句構病態** | 連續疊套「的…的…的」 | 英文形容詞子句多重修飾堆疊 | 拆解為獨立子句，或改為主謂賓明確的短句 |
| | 標題濫用「：」代替動詞 | 將英文副標題冒號生搬硬套 | 改用全形空格「　」或直接融入主被動句 |
| | 標題使用「…嗎？」反問 | 英文問句標題直譯，缺乏新聞篤定感 | 改為主動論斷（例如：「…恐難成局」、「…成效受質疑」） |
| | 被動句濫用（被認為是…） | 英文 passive voice 直譯 | 主動交代主體（「各界普遍看好…」、「學者評估…」） |

## 五、研究結論與執行方針

1. **標題製作**：嚴守 12–24 字上限，兩子句間以全形空格「　」區隔，冒號僅保留給發言或權威機構引述；一律將問號改寫為主動判斷。
2. **內文精煉**：徹底清除「進行」、「作出」、「該」等公文翻譯腔，數字與單位忠實保留，專有名詞依台灣中央社慣用語統一。
3. **觀點區隔**：遇到《經濟學人》的評論（Leaders），一律稱「經濟學人立場」或「作者主張」，嚴禁出現讀者排斥的「社論」字眼。
